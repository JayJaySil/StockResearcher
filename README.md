# StockResearcher

A personalised stock research app for companies listed on the **Stock Exchange of Thailand (SET)**. Build a watchlist, view price and financial data, track dividends, and get AI-generated summaries of a company's annual report (Form 56-1).

> **Disclaimer:** StockResearcher is for educational and informational purposes only. It is not financial advice.

## Features

- **Accounts**: email and password sign-up and sign-in with [Better Auth](https://www.better-auth.com/); protected routes redirect signed-out users to the home page
- **Watchlist**: add SET stocks by symbol (validated against the SETSMART API) and mark favourites
- **Company dashboard**: current quote information and a price chart
- **Dividends**: upload a spreadsheet of dividend history and see it as a dividend yield chart
- **Financial data**: quarterly and yearly financial statements and ratios for the last five years
- **56-1 Summariser**: upload a company's Form 56-1 PDF and get a summary generated by Google Gemini, saved to the database

## Getting Started

### Prerequisites

- Node.js 20+
- A MongoDB database (local or [MongoDB Atlas](https://www.mongodb.com/atlas))
- A SETSMART API key
- A Google Gemini API key

### Installation

```bash
git clone https://github.com/JayJaySil/StockResearcher.git
cd StockResearcher
npm install
```

### Environment variables

Create a `.env` file in the project root:

```env
# Database
MONGODB_URI=your_mongodb_connection_string

# Authentication
BETTER_AUTH_SECRET=a_long_random_string
BETTER_AUTH_URL=http://localhost:3000

# SETSMART market data
SETSMART_API_KEY=your_setsmart_api_key

# Gemini (56-1 summariser)
GEMINI_API_KEY=your_gemini_api_key
GEMINI_MODEL_ID=your_gemini_model_id          # optional
GEMINI_FILE_ACTIVATE_TIMEOUT_MS=60000         # optional
```

### Run the app

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000), create an account, and add a stock symbol to your watchlist.

### Other scripts

```bash
npm run build   # production build
npm run start   # run the production build
```

## Project Structure

```
app/
├── (auth)/          # sign-in and sign-up pages
├── (root)/          # home page with the watchlist
├── (company)/       # dashboard, financial and summariser pages
└── api/ai/          # Gemini 56-1 summarise route
components/          # UI components, charts and forms
database/            # Mongoose connection and models
lib/
├── actions/         # server actions (SETSMART, watchlist, dividends, auth)
└── better-auth/     # auth configuration
middleware/          # redirects unauthenticated users
types/               # global type declarations
```

## Data Sources

Prices, quotes and financials come from the SETSMART API. Summaries are produced by Google Gemini from the PDF you upload, so check them against the original filing.
